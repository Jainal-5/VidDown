# VidDown
A text-based program to download videos in bundle from supported sites using ytdlp library
## Features:
- Download videos in bundle from the list of supported sites.
- Add multiple sessions to a json file to keep tract of your downloads.
- Access sessions by index or anime title.
- Set a video title for every episodes in a session.

## Supported Sites:
- Gogoanime
- AnimeHeaven
